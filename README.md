### Обработка данных о выставочных экспонатах (вариант 6)

##### Запуск
Создание БД `backend/data/database.db` из Excel-файлов в `backend/tables` (существующая база пересоздаётся):
```
python backend/convert.py
```
Запуск сервиса:
```
streamlit run main.py
```

##### Возможности
* Просмотр таблиц VYST_MO, VUZ, GRNTIRUB.
* Сортировка НИР по составному ключу (код вуза + форма НИР + рег. №).
* Добавление, изменение и удаление НИР с проверками: уникальность ключа, наличие вуза в справочнике, формат и рубрика кода ГРНТИ.
* Фильтр: федеральный округ, субъект РФ, город, код ГРНТИ, наличие экспоната.
* Группы НИР: сохранение выделенных или отобранных записей, отметки о включении в выставку, выгрузка списка в CSV.
