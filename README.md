### Обработка данных о выставочных экспонатах (вариант 6)

##### Запуск
```
streamlit run main.py
```

При первом запуске к БД `backend/data/database.db` добавляются служебные таблицы (пользователи, группы НИР)
и суррогатный ключ `id` у таблицы НИР; перед этим создаётся резервная копия `database.bak.db`.

Чтобы проверить приложение на копии базы, укажите путь к ней в переменной `VYST_DB`:
```
VYST_DB=/путь/к/копии.db streamlit run main.py
```

##### Вход
Просматривать данные можно без входа; добавление, изменение и удаление записей и работа с группами — только после входа.
Пользователь по умолчанию: `admin`, пароль задаётся переменной окружения `DB_ADMIN_PASSWORD`
при первом запуске (если не задана — `admin`). Пароли хранятся в таблице `users` в виде хеша PBKDF2.

##### Возможности
* Меню «Данные» / «Группы» вверху, под ним таблица, ниже — выбор таблицы и все действия.
* Составной ключ НИР: код вуза + форма НИР + регистрационный номер; сортировка по нему по возрастанию/убыванию.
* Добавление и редактирование записи в отдельном окне с проверками: уникальность составного ключа, наличие вуза в справочнике,
  формат кода ГРНТИ (ввод по группам цифр ХХ.ХХ.ХХ, до двух кодов) и наличие рубрики, согласованность полей экспоната.
  После сохранения курсор ставится на добавленную/изменённую строку.
* Удаление записи с подтверждением.
* Фильтр: федеральный округ, субъект РФ, город (по справочнику вузов), рубрика или код ГРНТИ, степень готовности экспоната.
* Группы НИР: сохранение отобранных/выделенных записей в поименованную группу вместе с условиями фильтрации,
  отметки о включении НИР в выставку, документ «Список группы» (HTML для печати, CSV), карточка НИР.
